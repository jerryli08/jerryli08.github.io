Kindred Board Game

A Candy Land style board game for the novel Kindred, designed in CAD.

Overview

For an English project I designed a Candy Land style board game in CAD, based on the novel Kindred by Octavia E. Butler. The path runs from Maryland in the early 1800s to Altadena, California, in 1976.
