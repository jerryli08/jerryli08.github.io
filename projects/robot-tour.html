Science Olympiad Robot Tour

A navigation robot on an optical flow sensor, and a lesson in accumulated drift.

Overview

I built this robot by myself for the 2024-25 Science Olympiad Robot Tour event.

It navigated with an optical flow sensor, which was not accurate enough: it drifted over time, and the accumulated error pulled the robot's position estimate away from where it actually was.
